# Typography and code motion

Open on a code question the viewer can solve. Keep the source line stable while the narrated edit happens. In SE-0001, highlight only the backticks in Swift orange and remove them on the spoken cue. Word-level title motion settles before sustained reading. The graphite theme uses separate syntax colors for calls, keywords, escaped identifiers and types.

YouTube retention guidance motivated the opening; its actual effect on this channel remains unmeasured. The visual analogy came from 3Blue1Brown’s ring-to-area demonstration.

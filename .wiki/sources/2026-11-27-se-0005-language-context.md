# Objective-C and imported names in SE-0005

Apple’s archived language guide describes Objective-C as an object-oriented programming language used for iOS and Mac software. Its messaging syntax helps explain the bracketed UIKit call shown in the episode. [Apple language guide](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/ProgrammingWithObjectiveC/Introduction/Introduction.html)

In January 2016, Dave Abrahams described a mismatch between names imported from Cocoa and those in the Swift standard library. Inconsistent names made calls less predictable for Swift developers. He included drawing operations on a UIKit path as examples. His post describes the review in progress. For the spelling that shipped, consult the [episode evidence](../../episodes/SE-0005/research.md). [Swift project account](https://www.swift.org/blog/swift-api-transformation/)

The creator requested this context before the naming puzzle. Both editions introduce the language, toolkit and naming problem before comparing the Swift proposals. [Reading sheet](../../episodes/SE-0005/reading-ko.md)

# Series type selection

Creator decision: “애플 폰트와 menlo로 고정”

Use Apple system typography for titles, names and explanation text. Use Menlo for Swift code. Allow Apple SD Gothic Neo to supply Hangul glyphs in code comments. Apply the same families in landscape, portrait and thumbnails.

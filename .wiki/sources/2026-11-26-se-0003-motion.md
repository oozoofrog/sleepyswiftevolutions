# SE-0003 motion revision

The creator requested a revision using Disney animation principles. In both edits, the sending cell compresses before the value moves. The value accelerates along a shallow arc, slows at the destination, and the receiving cell briefly compresses on contact. Only the inout scene sends a value back.

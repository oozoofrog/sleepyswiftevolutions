# Proposal archive and episode progress

The [official proposal directory](https://github.com/swiftlang/swift-evolution/tree/58a97fabc7233f58af6b8a1e8d3d5a25fb4f7060/proposals) contains 605 files at the synchronized revision. The feed assigns 569 proposal IDs. Two numbered documents share SE-0519. Use the feed link to select the canonical document for each episode.

Run `pnpm evo sync --documents` to refresh and verify source files. Use `pnpm evo status --all` to see series coverage and `pnpm evo list --state all` to see progress for both formats. Downloading a document does not start an episode.

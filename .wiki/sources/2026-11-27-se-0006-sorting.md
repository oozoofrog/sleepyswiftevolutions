# Which call preserves the finish order?

The SE-0006 API diff maps the old value-returning `sort()` to `sorted()` and the old mutating `sortInPlace()` to `sort()`. Radek Pietruszewski argued during review that a short name could encourage use of the nonmutating operation. The March decision accepted the revised proposal. [January diff](https://github.com/swiftlang/swift-evolution/blob/9bb6efeb8d85/proposals/0006-apply-api-guidelines-to-the-standard-library.md) · [Review comment](https://forums.swift.org/t/review-se-0006-apply-api-guidelines-to-the-standard-library/1163/6) · [Decision](https://forums.swift.org/t/accepted-with-modifications-se-0006-apply-api-guidelines-to-the-standard-library/1667/1)

# YouTube feature access

On 2026-11-26 the creator reported completing phone verification. The earlier Studio screen said ID verification was unavailable. A subsequent check in Chrome showed intermediate features enabled, advanced features disabled, and a video verification link in the advanced feature notice. Eligibility beyond the link was not tested.

Phone verification enables intermediate features. For advanced features, the primary owner can use video or ID verification if offered. The channel can also qualify by building sufficient history. YouTube usually reviews a submitted verification video within 24 hours. [YouTube feature access](https://support.google.com/youtube/answer/9891124?hl=ko)

A Short needs advanced feature access to link to a public or unlisted episode as its related video. [YouTube Shorts guidance](https://support.google.com/youtube/answer/14075157?hl=ko)

Later on 2026-11-26 the creator reported submitting video verification. The open Studio panel still displayed advanced features as disabled. Approval has not been confirmed.

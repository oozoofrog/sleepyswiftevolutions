# 백틱이 사라졌다

칠과 일을 읽은 뒤 한 박자 쉽니다. 코드 전체는 화면으로 보여주고, 목소리는 지금 볼 단어만 짚습니다.

## 본편

### 7을 어디에서 찾는지 읽어봅니다

```swift
let list = [4, 7, 9]
indexOf(7, `in`: list)
```

세 숫자 가운데 칠이 몇 번째 자리에 있는지 찾아봅니다.

아래 줄을 보면, 칠 다음에 목록 이름이 나옵니다.

그 사이에 있는 in은 어디에서 찾을지를 알려 줍니다.

예전 스위프트에서는 그 짧은 단어 양옆에 백틱을 하나씩 써야 했습니다.

### 이름을 읽는 두 가지 자리

```swift
for item in list { }
indexOf(7, `in`: list)
```

반복문에서 in은 스위프트 문법의 일부입니다.

함수를 부르는 아랫줄에서는 역할이 달라집니다.

콜론 앞에서 다음 값이 무엇인지 알려 주는 이름입니다. 이런 이름을 인자 레이블이라고 합니다.

2015년 11월, 더그 그레거는 이 자리에서는 키워드도 그대로 쓰자고 제안했습니다.

### 이름을 바꾸면 해결될까

```swift
indexOf(7, within: list)
event.touchesMatching([.Began], `in`: view)
```

새 함수를 만드는 사람이라면 이름을 within으로 고를 수도 있었습니다.

이미 있던 Objective-C 코드를 스위프트로 가져올 때는 사정이 달랐습니다.

아래는 어느 뷰 안에서 터치가 일어났는지 묻는 호출입니다. 여기에도 in이 어울립니다.

제안서가 살핀 가져오기 사례에서는 이름을 고치거나 백틱을 붙여야 하는 API가 이백 개 가까이 됐습니다.

### 왜 in 하나만 고치지 않았을까

```swift
indexOf(7, in: list)
NSXPCInterface(protocol: SomeProtocolType.Protocol)
```

그중 키워드와 부딪힌 사례의 약 90퍼센트는 in이었습니다.

그래서 제안서에는 in 한 단어만 특별히 취급하는 방법도 나옵니다.

그렇게 하면 아래 줄의 프로토콜처럼 다른 키워드는 여전히 백틱으로 감싸야 합니다.

채택된 방법은 단어가 놓인 자리를 보는 것이었습니다. 호출 괄호 안에서 이름 다음에 콜론이 오면 레이블로 읽을 수 있습니다.

### 선언에는 예외가 남았습니다

```swift
func search(in list: [Int])
func addParameter(name: String, `inout`: Bool)
```

함수를 선언할 때도 목록 앞에 in을 쓸 수 있게 됐습니다.

다만 당시 선언에서 인아웃과 바, 렛은 매개변수의 성질을 지정하는 말이었습니다.

그래서 두 번째 줄처럼 인아웃 자체를 이름으로 쓰려면 백틱이 필요했습니다.

### 다시 같은 목록에서 찾습니다

```swift
indexOf(7, `in`: list)
indexOf(7, in: list)
// 1
```

이 변경은 2015년 12월에 구현 완료로 기록됐고, 2016년 3월에 나온 Swift 2.2에 실렸습니다.

처음 보았던 호출에서 백틱 두 개를 빼 봅니다.

지금의 스위프트로 두 줄을 각각 실행해도 결과는 일입니다. 배열의 첫 자리를 영으로 세기 때문입니다.

칠을 찾는 방법은 그대로입니다. 어디에서 찾는지 알려 주는 in을 이제는 그대로 읽을 수 있습니다.

## 쇼츠

### 어디에서 찾는지 알려 주는 이름

```swift
let list = [4, 7, 9]
indexOf(7, `in`: list)
```

목록에서 칠을 찾는 코드입니다.

예전 스위프트에서는 어디에서 찾는지 알려 주는 in에 백틱을 붙였습니다.

### 콜론 앞의 in

```swift
for item in list { }
indexOf(7, in: list)
```

반복문에서는 in이 문법의 일부입니다.

하지만 함수를 부를 때는 바로 뒤에 콜론이 있어 이름이라는 걸 알아볼 수 있습니다.

덕분에 2016년 3월에 나온 Swift 2.2부터는 이 자리의 백틱을 생략할 수 있게 됐습니다.

### 같은 칠을 찾습니다

```swift
indexOf(7, `in`: list)
indexOf(7, in: list)
// 1
```

백틱을 쓴 호출도 계속 동작합니다.

두 줄 모두 같은 목록에서 같은 칠을 찾습니다. 결과도 일로 같습니다.

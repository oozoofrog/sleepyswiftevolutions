# 유니코드 1.0 연대기 — 사람과 사건

유니코드 컨소시엄의 영문 연대기는 제록스의 한자 대응표 작업으로 시작해 1992년 9월 컴퓨터 잡지 기사로 끝난다. 아래 표는 그 원문을 따라가며 oozoofrog의 한국어 글에 붙은 날짜 소제목 48개를 여섯 이야기로 묶은 것이다. 초판의 사례와 참여자의 회고는 해당 장에 따로 표시했다. 블로그의 괄호 속 감상은 필자의 목소리다. 예를 들어 1987년 4월 방문자 피터 펜윅을 펜윅 트리의 고안자로 보는 설명은 필자의 추정이다. 영문 연대기는 방문자의 소속이나 이후 업적을 밝히지 않는다. [컨소시엄 영문 원문](https://www.unicode.org/history/versionone.html) · [oozoofrog의 한국어 연대기](https://oozoofrog.dev/blog/chronology_unicode/)

영상은 1988년 8월 29일 조 베커가 작성한 「Unicode 88」로 시작한다. 베커는 여러 언어의 글자를 표현할 공통 부호 체계를 제안했고, 개별 글자의 번호는 후속 작업으로 남겼다. 도입부에 나오는 U+3131은 오늘날 유니코드에서 한글 호환 자모 ‘기역’(ㄱ)에 쓰는 번호다. [제안서 표지와 1.1절](https://www.unicode.org/history/Unicode88.pdf)

첫 화면의 ‘기역’(ㄱ)은 초판의 인쇄 질감을 입힌 작은 활자들을 겹쳐 만들었다. 카메라가 그 꺾임 획 속으로 들어갔다가 물러날 때 드러나는 제록스 연구소 이름은 조 베커가 1988년에 쓴 제안서의 3.1절에서 가져왔다. 이어지는 내레이션은 그보다 앞선 1986~1987년의 문자표 대조 작업을 다루며, 6장에서는 세 나라의 한자 대조표를 ‘한 일’(一, U+4E00)로 비교한다. [제안서 11쪽](https://www.unicode.org/history/Unicode88.pdf#page=11)

## 1. 제록스와 애플이 같은 문제를 만나다

토론토의 제록스 사용자 나카지마는 중국 문자표에 없는 한자를 일본 JIS 문자표에서 찾아 썼다. 글꼴을 확장하려던 제록스 팀에는 일본 문자표의 어느 항목이 중국 간체·번체의 어떤 항목에 해당하는지 알려 줄 자료가 필요했다. 후안메이 랴오(Huan-mei Liao), 넬슨 응(Nelson Ng), 데이브 옵스타드(Dave Opstad), 리 콜린스(Lee Collins)가 그 관계를 기록했다. 에릭 메이더는 한자 통합에 대한 찬반 논거를 정리했다. 애플의 출발점은 파일 교환이었다. 마크 데이비스는 일본에서 매킨토시를 현지화했던 경험을 회고하며, 여러 언어를 지원하려면 개발자가 문자 체계마다 코드를 달리 짜야 했던 문제를 설명했다. [참여자들의 회고](https://www.unicode.org/history/earlyyears.html) · [연대기 첫 항목](https://www.unicode.org/history/versionone.html)

| 한국어 글의 항목 | 인물과 사건 |
|---|---|
| 1986~1987 | 제록스 팀이 같은 한자를 대조한다. 애플에서는 파일 교환 프로그램을 개발하며 범용 문자 집합을 논의한다. |
| 1987년 4월 | 피터 펜윅이 제록스를 방문한다. 원문은 이 방문을 0부터 글자에 차례로 번호를 붙이는 구상과 연결한다. 앨런 터커와 캐런 스미스요시무라 등도 참석했다. |
| 1987년 가을 | 베커의 제록스 팀과 데이비스가 인코딩을 논의한다. 옵스타드는 제록스의 기존 압축 방식 운용 경험을 근거로 고정 길이를 선호한다. |
| 1987년 12월 | 베커가 지은 이름 ‘Unicode’의 가장 이른 문서 기록이 남는다. |

## 2. 한 글자를 몇 바이트로 저장할까

기종마다 다른 표를 서로 직접 변환하면 상대 기종이 늘 때마다 변환 작업도 늘어난다. 베커는 각 시스템을 공통 코드에 연결하는 방법을 설명했다. 당시 제안한 16비트 설계는 저장 공간과 글자를 찾아가는 비용 사이에서 내린 판단이었다. 한편 도서관에서는 이미 다른 문제를 풀고 있었다. 사서가 한·중·일 책의 제목을 원래 문자로 한 번 입력하면 다른 도서관도 그 서지 기록을 가져다 쓸 수 있었다. 스미스요시무라는 이 서비스가 1983년에 시작됐다고 기록했다. 1988년 애플이 산 것은 도서관 연구그룹 RLG의 **CJK 문자 데이터베이스**다. 도서 목록 전체를 인수한 사건과 구별한다. [베커의 제안서](https://www.unicode.org/history/Unicode88.pdf) · [스미스요시무라의 도서관 기록](https://scholarsarchive.byu.edu/jeal/vol1993/iss101/12/)

| 항목 | 인물과 사건 |
|---|---|
| 1988년 2월 | 애플로 옮긴 콜린스가 데이비스의 제안을 검토한다. 고정·가변 길이의 접근 비용, 저장 용량, 필요한 문자 수를 조사한다. |
| 1988년 4월 | 애플이 문자 처리 시제품을 만들고 트루타입에 유니코드를 지원하기로 한다. |
| 1988년 여름 | 팔로알토에서 베커와 콜린스가 RLG의 터커·스미스요시무라와 한자를 통합할 기준을 논의한다. |
| 1988년 7월 | 애플이 한자 통합 연구에 쓸 RLG의 한·중·일 문자 데이터를 구입한다. |
| 1988년 9월 | 베커와 콜린스가 미국 표준화 회의에 한자 통합을 제안한다. 베커의 글 「Unicode 88」에는 8월 29일 날짜가 적혀 있다. |
| 1988년 10월 | 에드 스무라의 권유로 두 사람이 도쿄 회의에 참석한다. 후지제록스에서 한자 대조 도구를 시연한다. |
| 1988년 11월 | 콜린스가 한자 이외의 문자 이름과 변환 관계를 담을 데이터베이스를 만들기 시작한다. |

## 3. 한 번호로 합치면 원문으로 돌아갈 수 있을까

유니코드 1.0 제2권은 대만 표준에서 다른 두 글자로 구분한 青과 靑을 예로 든다. 두 문자를 같은 번호로 합치면 유니코드를 거쳐 원래 문자표로 돌아왔을 때 어느 쪽이었는지 판별할 수 없다. 비슷하게 보이는 글자의 수를 줄이는 일과 문서의 구별을 보존하는 일 사이에 실제 충돌이 있었다. [초판 제2권 16쪽](https://www.unicode.org/versions/Unicode1.0.0/V2ch02.pdf#page=6)

| 항목 | 인물과 사건 |
|---|---|
| 1989년 1월 | 콜린스가 제록스 측과 자료 교환을 논의한다. 메타포는 16비트 인코딩을 채택하기로 한다. |
| 1989년 2월 | 켄 휘슬러·마이크 커너핸과 RLG의 조앤 앨리프랜드·스미스요시무라 등이 회의에 참여한다. 글렌 라이트가 전자우편 토론을 운영한다. |
| 1989년 3월 | 콜린스가 하이퍼카드로 한자 데이터베이스를 구축한다. 5월까지 한국 KS를 포함한 기존 표준의 수록 문자를 정리한다. |
| 1989년 4월 | 작업 그룹이 기존 표준과의 왕복 변환을 보장하기로 한다. |
| 1989년 5월 | 홍콩 회의에서 AFII가 한자 통합을 지지한다. |
| 1989년 8월 | 베커와 콜린스가 두 회사의 자료를 합친다. 기존 표준 하나가 따로 둔 두 글자의 구별은 유지한다. 중동·인도계 문자에는 논리적 순서를 쓰기로 한다. |
| 1989년 9월 | 첫 초안이 미국 표준화 회의에 제출된다. 한자 배열 방식과 문자 명칭도 협상 대상이 된다. |
| 1989년 10월 | 베이징 회의에서 사람이 찾아보기 쉬운 한자 배열이 논의된다. 암만 회의에서는 결합 부호를 다룬다. |
| 1989년 11월 | 코라 장이 일본·중국 표준과의 추가 대응 관계를 조사한다. |
| 1989년 12월 | 콜린스는 트루타입 행사에서, 베커는 유닉스 국제화 회의에서 유니코드를 소개한다. |

## 4. 한 나라가 정할 수 없는 기준

한국 대표단은 서울 회의에서 여러 나라가 함께 한자를 검토할 연구그룹을 제안했다. 초판 제2권 본문은 대표단의 제안이라고 기록하며 개인 발언자를 특정하지 않는다. 다만 **당시 문서대장과 초판 ‘감사의 글’(Acknowledgments)**에는 한국 측 실명과 소속이 남아 있다. 1990년 X3L2 문서대장에는 2월 서울 WG2 회의 안내문(`90-19K`) 작성자이자 ISO 10646 한국 측 입장 서신(`90-131`) 수신자로 **조정성(Jeoung Sung Cho, J.S. Cho)** 이 기록돼 있고, 제2권 감사의 글(`V2Acknowledge.pdf`)은 한·중·일 공동연구그룹(CJK-JRG) 한국 수석대표로 공업진흥청 표준국의 **오영택(Oh Young-taik)**, 공동목록 최종 검토를 맡은 CJK-JRG 편집소위원회 한국 위원으로 공주대학교 **이춘택(Lee Choon Tack)** 교수를 적었다. **날짜에는 자료 차이가 있다.** 영문 연대기와 블로그에는 서울 회의가 3월 항목에 있다. 초판 제2권 12쪽은 2월을 명시한다. 당시 문서대장의 회의 안내는 2월 26~28일, 보고서 날짜는 3월 2일이다. 영상에는 회의 시점을 2월로 썼다. [당시 문서대장](https://www.unicode.org/L2/L1990/Register-1990.html) · [초판 제2권 12–13쪽](https://www.unicode.org/versions/Unicode1.0.0/V2ch02.pdf#page=2) · [초판 제2권 감사의 글](https://www.unicode.org/versions/Unicode1.0.0/V2Acknowledge.pdf)

| 항목 | 인물과 사건 |
|---|---|
| 1990년 1월 | 마이크로소프트의 미셸 쉬냐르와 아스무스 프라이타크가 회의에 참석하기 시작한다. 콜린스는 일본 측 의견을 번역한다. |
| 1990년 3월 | 연대기는 이 항목에 서울 회의를 싣는다. 강희자전의 부수·획수에 기초한 배열이 배포된다. |
| 1990년 4월 | 워싱턴 회의에서 미국 측 제안이 받아들여지지 않는다. 결합 부호를 둘러싼 이전 결정도 뒤집힌다. |
| 1990년 5월 | 베커의 문자 이름 초안을 바탕으로 휘슬러가 이름·대응 관계 데이터베이스를 구성한다. |
| 1990년 6월 | IBM이 정기적으로 참여하기 시작한다. |
| 1990년 7월 | 제임스 콜드웰이 문서 편집을 맡고, 휘슬러가 한자 이외의 문자 데이터베이스를 인계받는다. 임시 임원도 정해진다. |
| 1990년 8월 | 이사이 샤인버그가 IBM 내부 검토와 토론토대 한자 연구를 조직한다. |
| 1990년 9월 | IBM 검토 뒤 반각 문자와 아랍 문자 자형을 위한 호환 영역이 반영된다. |
| 1990년 10월 | 토론토대가 한자 초안을 검토한다. 프라이타크의 소위원회는 양방향 글의 순서를 다룬다. |
| 1990년 11월 | 최종 검토안이 국제적으로 배포되고 데이비스가 콜린스와 함께 쓴 논문을 발표한다. |
| 1990년 12월 | 남아시아 문자의 논리적 순서를 채택하고 길이 표시를 반영한다. 한자 이외에도 입력 순서와 표시 순서라는 별도 문제가 있었다. |

## 5. 초판이 두 권으로 나온 이유

출판사는 원고를 기다렸고, 표준화 회의에서는 별도의 국제 문자 표준인 ISO 10646을 논의하고 있었다. 원고를 넘긴 뒤에도 두 체계의 번호와 문자 목록을 조율해야 했다. 첫 책의 109쪽에는 한자 수록을 다음 권으로 미룬 흔적이 남아 있다. [영문 연대기](https://www.unicode.org/history/versionone.html) · [초판 발행 기록](https://www.unicode.org/versions/Unicode1.0.0/)

| 항목 | 인물과 사건 |
|---|---|
| 1991년 1월 | 3일에 컨소시엄 법인이 설립된다. 25일 첫 이사회가 열리고 작업 그룹은 기술위원회로 전환된다. |
| 1991년 2월 | 앤드루 폴랙이 뉴욕타임스에 소개 기사를 쓴다. 에리카 리더먼이 책의 편집자로 합류한다. |
| 1991년 3월 | 종일 편집 회의를 열고 5월 7일을 원고 전달 목표로 잡는다. |
| 1991년 4월 | 미국은 ISO 초안에 반대 입장을 낸다. 편집진은 원고 전달 목표를 유지한다. |
| 1991년 5월 | 8일 교정 전 원고를 출판사에 전달한다. 아직 출간 전이다. |
| 1991년 6월 | ISO 10646 초안이 부결된다. 샌프란시스코에서 두 표준을 조율하는 작업이 시작된다. |
| 1991년 7월 | 한·중·일 공동연구그룹(CJK-JRG)이 출범한다. 도쿄 첫 공식 회의에서 중국·유니코드 측이 합친 목록과 미야자와 아키라 등 일본 대표단의 검토 기준을 다룬다. 책을 두 권으로 내기로 한다. |
| 1991년 8월 | 제작용 원고가 출판사에 전달된다. 제네바 회의에서 한자 통합을 포함한 주요 사항을 받아들인다. |
| 1991년 9월 | 베트남어 사전 조합 문자의 수록이 논의된다. 이는 훗날 콜린스가 검토한 베트남의 옛 한자계 문자와 다른 사안이다. |
| 1991년 10월 | 원문은 18일에 제1권이 도착해 배포됐다고 기록한다. 제2권 계획은 계속 논의 중이다. |
| 1991년 11~12월 | 애플이 UniHan 데이터를 컨소시엄에 라이선스한다. 공동연구그룹의 한자 통합안이 수용된다. |

## 6. 인쇄된 표에서 ‘一’의 세 번호를 읽다

| 항목 | 인물과 사건 |
|---|---|
| 1992년 1~2월 | 제2권 교정 중 한자 배열 문제가 남아 공동연구그룹 회의까지 발행을 미룬다. |
| 1992년 3월 | 공동연구그룹이 한자 변경을 승인한다. 27일 확정된 URO 2.0은 한자 목록과 순서를 가리킨다. |
| 1992년 4~5월 | 구현 교육과 워크숍을 준비하는 한편, 제2권의 인쇄용 원고를 넘긴다. |
| 1992년 6월 | 제2권을 인쇄한다. 대조표에서 一(U+4E00)은 중국 표 50행 27열, 일본 표 16행 76열, 한국 표 76행 73열에 대응한다. |
| 1992년 9월 | 존 C. 드보락이 PC Magazine에 「Kiss Your ASCII Goodbye」를 싣는다. 영문 연대기는 이 기사로 끝난다. |

6장의 대조표 예시 글자 一은 이 과정을 설명하려고 고른 예다. 제록스가 처음 대조한 글자라는 기록은 없다. 1992년 9월 15일자 기사([원문 스캔](https://www.unicode.org/announcements/kissascii.pdf))의 필자 **존 C. 드보락(John C. Dvorak, 1946–2026)** 은 컴퓨터 칼럼니스트이며, 1930년대에 영문 드보락 자판을 고안한 워싱턴 대학교 교육심리학자 **오거스트 드보락(August Dvorak, 1894–1975)** 과는 다른 인물이다(여러 약력과 인터뷰에서는 오거스트 드보락을 존 C. 드보락의 숙부·친척으로 소개한다). [초판 한자 대조표 171쪽](https://www.unicode.org/versions/Unicode1.0.0/HanCharts2.pdf#page=3)

## 에필로그 — 사람들이 이후에 남긴 기록

2026년 11월 27일에 확인한 공개 자료를 기준으로, 직책이나 활동이 확인되는 해를 사람마다 따로 적었다. 영상에 쓰인 베커와 데이비스의 인물 사진은 컨소시엄이 공개한 자료이며 촬영 연도는 표기되지 않았다. [컨소시엄 사진 기록](https://www.unicode.org/history/photoalbum/)

- **조 베커**는 유니코드 컨소시엄의 초대 기술 부회장으로 1991년부터 1998년까지 일했다. 컨소시엄은 그를 역대 임원으로 소개한다. 그 이후의 현직이나 사생활은 이 자료로 확인할 수 없다. [컨소시엄 역대 임원](https://www.unicode.org/consortium/formerleaders.html)
- **캐런 스미스요시무라**는 1993년에 도서관의 한·중·일 문자 서비스 10년을 기록했다. 2020년 OCLC에서 은퇴했다. 2023년 4월 구술 인터뷰에서 1983년 첫날을 회고했다. 미국 의회도서관이 첫 기록을 입력할 수 있도록 다른 도서관들이 잠시 기다려 줬다는 기억이다. [본인의 1993년 논문](https://scholarsarchive.byu.edu/jeal/vol1993/iss101/12/) · [OCLC 은퇴 기록](https://www.oclc.org/content/dam/campaign-landing-pages/en/next-generation-of-metadata/resources/Transitioning-to-the-Next-Generation-of-Metadata-Opening-Plenary-February2021.pdf) · [2023년 구술 기록, 인쇄 쪽수 120–121](https://knowledge.uchicago.edu/record/10054/files/%E7%AC%A6%E4%BB%A5%E8%BD%BD%E9%81%93.pdf)
- **마크 데이비스**는 이후 여러 언어의 날짜·숫자 표기 같은 정보를 정리하는 CLDR 프로젝트를 시작했다. 2025년 이사회 의장직을 넘겼다. 2026년 9월 컨소시엄은 그의 이름을 딴 상과 스탠퍼드 강연을 소개했다. 첫 시상과 강연은 2027년 예정으로 공지됐다. [컨소시엄 인사 발표](https://blog.unicode.org/2025/02/unicode-welcomes-new-board-leader-and.html) · [2026년 9월 발표](https://blog.unicode.org/2026/09/recent-unicode-happenings-september-2026.html)
- **리 콜린스**의 이름은 2026년 2월 4일자 베트남 측 제안서에서도 확인된다. 에이소 찬, 응오 쭝 비엣과 함께 따이(Tày)어로 ‘누구’를 뜻하는 글자를 검토했다. 이미 등록된 U+2B8A0과 새 후보의 글자꼴·음가를 사전과 대조하고 기존 항목의 수정을 제안했다. 문서는 제안 단계다. 1980년대의 ‘같은 글자인지 어떻게 아는가’라는 문제를 자료와 함께 다시 볼 수 있는 사례다. [세 사람이 제출한 제안서](https://www.unicode.org/L2/L2026/26068-v-source-character-u2b8a0.pdf)
- **넬슨 응**은 제록스 팀에서 한자를 대조한 뒤 이베이의 UTF-8 전환 사례를 유니코드 회의에서 소개했다. 팔로알토 박물관은 현재 그를 이사장으로 소개한다. 1982년 제록스 여름 인턴으로 이 도시와 인연을 맺었고, 2019년 박물관 이사회에 합류해 2025년 7월 이사장이 됐다. [컨소시엄의 2006년 회의 안내](https://www.unicode.org/mail-arch/unicode-ml/y2006-m06/0336.html) · [박물관 공식 약력](https://paloaltomuseum.org/team-member/nelson-ng/)
- **미야자와 아키라**는 당시 일본 대표단 동료들과 한자 통합의 검토 기준을 마련했다. 2011년에는 문자 코드와 각국의 한자 차이를 시민에게 설명하는 강연을 예고했다. 일본 국립정보학연구소는 현재 그를 명예교수 명단에 올리고 있다. [연구소 강연 안내](https://www.nii.ac.jp/mail/archives/2011/0927.html) · [연구소 명예교수 명단](https://www.nii.ac.jp/en/faculty/emeritus/)
- **공동연구그룹의 후신 IRG**는 2026년 10월에도 도쿄에서 제67차 회의를 열었다. 이것은 조직의 활동 기록이다. 1991년 참석자 개개인의 근황을 뜻하지 않는다. 제록스 초기 팀의 랴오·옵스타드와 서울 회의 대표단은 영상에서 당시 자료에 확인되는 역할로 소개하며, 초판 감사의 글과 대학 공식 기록이 확인되는 오영택·이춘택·김경석은 공동연구그룹 장면과 후일담에 실명으로 담았다. [IRG 회의 기록](https://www.unicode.org/irg/meetings.html)
- **오영택(공업진흥청 표준국 과장)** 은 초판 제2권 감사의 글(`V2Acknowledge.pdf` v쪽)에 일본의 미야자와 아키라, 중국의 장저우차이 등과 함께 CJK-JRG 주요 대표단장으로 올랐다. 국립국어원 연혁(`6. 한자 표준화`)에도 1992년 11월 30일~12월 4일 하와이 제5차 CJK-JRG 국제회의에 공주대학교 현규섭 교수(단장), 문화부 임원선 사무관, 동양학연구소 서지원 전문위원, 한국 IBM 김철 차장, 국립국어연구원 조남호 연구원과 함께 한국 측 대표로 참석해 확장 한자 6,664자를 제출한 기록이 남아 있다. [초판 제2권 감사의 글](https://www.unicode.org/versions/Unicode1.0.0/V2Acknowledge.pdf) · [국립국어원 한자 표준화 연혁](https://www.korean.go.kr/nkview/history/h_13.html)
- **이춘택(공주대학교 사범대학 문헌정보교육과 명예교수)** 은 초판 제2권 감사의 글(`V2Acknowledge.pdf` v–vi쪽)에 통합 한자 목록(URO)의 최종 검토·검증을 맡은 CJK-JRG 편집소위원회 5인(리 콜린스, 가오톈추, 고이케 다테오, 이춘택, 장저우차이) 중 한국 위원으로 등재됐다. 공주대학교 학과 공식 페이지에는 1986~2008년 2월 재직 및 1990~1991년 CJK-JRG 한국 편집위원 경력과 한자코드 연구 분야가 명시돼 있다. [초판 제2권 감사의 글](https://www.unicode.org/versions/Unicode1.0.0/V2Acknowledge.pdf) · [공주대 문헌정보교육과 소개](https://lise.kongju.ac.kr/ZA0370/9944/subview.do)
- **김경석(부산대학교 정보컴퓨터공학부 명예교수)** 은 미국 노스다코타주립대 재직 시절 이미 초판 제1권(`Acknowledge.pdf` v–vi쪽)과 제2권(`V2Acknowledge.pdf` vi쪽) 모두에 표준 제정·검토 기여자로 이름을 올렸다. 귀국 후 부산대 교수 겸 공업진흥청 문자코드전문위원회(`Korea JTC1/SC2`) 의장으로서 1992년부터 `ISO/IEC JTC 1/SC 2/WG 2` 한국 대표로 참석해, 제1권 108쪽의 KS C 5601 완성형 2,350자(`U+3400`–`U+3D2D`)를 넘어 ‘첫가끝’ 한글 자모 조합 체계와 현대 한글 11,172자 정립을 이끌고 『컴퓨터 속의 한글 이야기』(1995)를 펴냈다. 현재 부산대학교 명예교수로 등재돼 있다. [초판 제1권 감사의 글](https://www.unicode.org/versions/Unicode1.0.0/Acknowledge.pdf) · [제1권 108쪽](https://www.unicode.org/versions/Unicode1.0.0/ch03_3.pdf#page=11) · [1995년 4월 13일 전자신문 보도](https://www.etnews.com/199504130047) · [부산대 PNU Scholar](https://scholar.pusan.ac.kr/researchers/1103/)
- **임혜영·정재·김해성**: 초판 제1·2권 감사의 글은 토론토대 동아시아학과 CJK 한자 통합 검증 프로젝트(팀장 나카지마 가즈코 교수)의 **임혜영(Hye-young Im)** 과 자문위원 **정재(Jae Chong, Hahn Computer Institute)**, 그리고 애플 소속 검토자 **김해성(Haesung Kim)** 을 함께 기록하고 있다. ## 쿠키 — 2026년 숫자로 보는 유니코드

인물 후일담과 `자료와 제작` 카드 뒤에 이어지는 쿠키는 2026년 11월 28일 기준 유니코드 컨소시엄 1차 자료로 정리한 최신 현황이다.

- **최신 판본과 전체 문자 수**: **유니코드 18.0.0**(2026년 9월 16일 발표)은 그래픽 문자와 서식 문자를 합쳐 **172,808자**를 수록했다(17.0 대비 13,007자 추가; 소전 11,328자·여진 문자·원시 쐐기 숫자 포함). 1991–1992년 유니코드 1.0(제1·2권 합산)의 28,294자와 대비된다. [유니코드 18.0 발표 요약](https://www.unicode.org/versions/Unicode18.0.0/) · [유니코드 18.0 문자 통계](https://www.unicode.org/versions/stats/charcountv18_0.html)
- **문자 체계와 지원 언어 수**: 유니코드는 개별 언어가 아니라 **175개 문자 체계(Script)**를 부호화해 현대와 고대의 수천 개 언어를 표기할 수 있게 한다(예: 로마자 한 체계로 수천 개 언어 기록). 날짜·숫자·통화 등 언어별 표기 규칙을 정리한 지역화 표준 **CLDR 49**(2026년 10월 22일 발표)는 현재 **172개 기본 언어**(100 Modern · 12 Moderate · 73 Basic, 총 185개 커버리지 로케일)를 공식 지원하며, 821개 언어의 문자 정보를 수록한다. [유니코드 FAQ](https://www.unicode.org/faq/basic_q.html) · [지원 문자 목록](https://www.unicode.org/standard/supported.html) · [CLDR 49 릴리스 노트](https://cldr.unicode.org/index/downloads/cldr-49)
- **고유 문자가 등록된 가장 희귀한 생활 언어**: 인도 서벵골주 부탄 접경 토토파라(Totopara) 한 마을에서 **약 1,500명**이 사용하는 중국티베트어족 **토토어(Toto, ISO 639-3 `txo`)**가 꼽힌다. 마을 원로 다니람 토토(Dhaniram Toto)가 2015년 5월 창제한 31자 알파벳은 버클리대 Script Encoding Initiative(데보라 앤더슨)의 제안을 거쳐 유니코드 14.0(`U+1E290–U+1E2BF`)에 등록됐다. 보충 비교로, 오세이지어(`U+104B0–U+104FF`)는 마지막 제1언어 모어 화자가 세상을 떠난 뒤 공동체가 제2언어 부흥을 위해 2006–2014년 문자를 제정해 올린 사례이고, 필리핀 타그반와 문자(`U+1760–U+177F`)는 UCD `Scripts.txt` 기준 **18자**로 배정 문자 수가 가장 적은 문자 체계다. [토토 문자 등록 제안서 L2/19-330](https://www.unicode.org/L2/L2019/19330-toto-script.pdf) · [유니코드 18.0 토토 문자표](https://www.unicode.org/charts/PDF/U1E290.pdf) · [UCD 18.0.0 Scripts.txt](https://www.unicode.org/Public/18.0.0/ucd/Scripts.txt)
- **번호를 가장 많이 쓰는 문자와 언어**: 동아시아에서 공유하는 **한자(CJK 통합한자 및 호환 한자)**가 **102,999자**(전체 172,808자의 **59.6%**)로 압도적 1위다(`Scripts.txt` 부수·획수 포함 `Han` 103,352자). 반대로 한 언어만 단독으로 쓰는 고유 문자 체계 가운데서는 **한국어 한글**이 완성형 현대 음절 11,172자를 포함해 **11,739자**로 전체 2위이자 단일 언어 전용 문자 1위다. [유니코드 18.0 문자 통계](https://www.unicode.org/versions/stats/charcountv18_0.html) · [UCD 18.0.0 Scripts.txt](https://www.unicode.org/Public/18.0.0/ucd/Scripts.txt)

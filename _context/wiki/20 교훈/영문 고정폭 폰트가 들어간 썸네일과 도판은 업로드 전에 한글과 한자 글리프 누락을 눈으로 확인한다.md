# 영문 고정폭 폰트가 들어간 썸네일과 도판은 업로드 전에 한글과 한자 글리프 누락을 눈으로 확인한다

> [!abstract] 한 문장
> `Menlo` 같은 영문 전용 고정폭 폰트를 썸네일이나 Pillow 도판에 쓸 때는 ASCII 코드만 고정폭 폰트로 그리고 한글·한자는 전용 서체로 분리한 뒤, 업로드 전에 생성된 이미지 파일을 직접 열어 두부 박스(`□`)가 없는지 눈으로 확인한다.

## 상황

Swift 코드나 유니코드 코드 포인트(`U+4E00`)를 한글 제목·설명이나 한자(`一`)와 한 줄에 섞어 PNG·JPEG 썸네일 또는 영상 도판을 렌더링할 때다.

## 일어난 일

브라우저 CSS에서는 `Menlo, "Apple SD Gothic Neo"` 폴백 체인이 자동으로 동작하지만, Python Pillow(`ImageFont.truetype`)로 `episodes/unicode-1.0/thumb.py` 썸네일을 처음 그렸을 때는 단일 폰트 파일(`Menlo.ttc`)에 한글·한자 글리프가 없어 누락 사각형(`□`)이 그대로 찍혔다. 업로드 직전 이미지 파일을 열어 육안 검수한 덕분에 공개 전에 잡았다.

## 왜 중요한가

파일 크기나 해상도 검사(`ffprobe`, 바이트 상한)만으로는 깨진 글리프 사각형(`□`)을 전혀 걸러내지 못하며, 한 번 공개된 썸네일은 YouTube API `429` 제한에 걸릴 경우 교체 비용도 크다.

## 이렇게 한다

- 지시하는 사람: 특별히 다른 조치는 필요 없으며, 새 시리즈 썸네일 첫 시안에서 서체 인상을 확인해 주면 충분하다.
- 에이전트: Pillow·Canvas 등 폴백 체인이 없는 렌더러에서는 `Menlo`를 ASCII 범위에만 쓰고 한글(`AppleSDGothicNeo`, `AppleMyungjo`)·한자(`Songti`) 호출을 분리한 뒤 반드시 생성된 이미지를 `read_file`로 열어 확인한다.

# 게시 전에 채널 업로드 목록을 확인한다

> [!abstract] 한 문장
> 외부 채널이나 프로필에 영상을 게시할 때는 파일을 올리기 전에 로컬 영수증과 실제 업로드 목록을 먼저 대조하고, 이미 올라간 항목은 기존 ID에서 나머지 설정만 이어간다.

## 상황

YouTube Data API 업로드나 인스타그램 웹 릴스 게시처럼 한 번 공개되면 되돌리기 번거로운 외부 배포 작업을 수행할 때다.

## 일어난 일

쿼터 초과로 API 호출이 중간에 멈추거나 여러 에피소드를 연속 게시할 때 로컬 상태만 보면 이미 비공개로 생성된 영상 ID나 기존 게시물을 놓쳐 중복 업로드를 일으킬 위험이 있었다. 사전 목록 대조를 습관화한 결과 5차례 배포 모두 중복 게시 `0`건을 유지했다.

## 왜 중요한가

중복 업로드가 발생하면 삭제·재업로드에 할당량과 처리 시간을 두 배로 쓰고 시청자 링크가 갈라진다. 게시 전 1회 조회만으로 중복 사고를 완전히 막을 수 있다.

## 이렇게 한다

- 지시하는 사람: 기존 채널·계정에 이어서 올리는 작업이면 평소처럼 `"업로드"`처럼 짧게 지시해도 된다.
- 에이전트: 상세 절차는 `encoded_in`에 등록된 게시 지침과 시리즈 스킬을 따른다.

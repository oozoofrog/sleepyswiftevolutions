# 새 플랫폼 게시나 다중 에이전트 위임 시 응답 언어와 대상 범위를 짧은 문장으로 함께 적는다

> [!abstract] 한 문장
> 영문 템플릿이 섞인 다중 에이전트 위임을 쓰거나 처음 올리는 외부 플랫폼에 게시를 맡길 때는 응답 언어(한국어)와 계정·대상 편수·자막 합본 여부를 짧은 한 문장으로 함께 적으면 되묻기나 영문 보고 없이 바로 끝난다.

## 상황

기존 YouTube 파이프라인처럼 관례가 굳어진 작업(`"6화 제작"`, `"업로드"`)과 달리, 영문 오케스트레이션 워커를 경유하거나 인스타그램 릴스처럼 처음 여는 배포 채널에 일괄 게시를 지시할 때다.

## 일어난 일

`2026-11-28` 새벽 Orca 워커 재개 템플릿에 `"When you finish, report in English"` 문구가 들어 있어 에이전트가 영어로 결과를 보고했고 사용자가 `"응답은 항상 한국어로 해주세요."`라고 한 번 더 교정해야 했다. 같은 날 오후 `"쇼츠들을 릴스로도 올려주세요"`에서는 대상 계정(`@oozoofrog`), 범위(7편 전체), 한국어 자막 번인 여부를 사전 질문 1회로 확정한 뒤 7편을 무실패로 마쳤다.

## 왜 중요한가

관례가 아직 없는 첫 작업에서 언어·계정·범위 조건 한 줄을 미리 적으면 왕복 1~2턴을 아끼고 잘못된 계정이나 무자막 판본이 올라갈 위험을 없앤다.

## 이렇게 한다

- 지시하는 사람: 새 플랫폼 첫 게시 때는 예컨대 `"공개된 쇼츠 7편 전부 @oozoofrog 릴스에 한국어 자막 합본으로 올려주세요"`처럼 계정·범위·자막 방식을 덧붙이고, 외부 위임 도구 사용 시 한국어 응답 고정 문구를 넣어 둔다.
- 에이전트: 시스템·워커 브리프가 영어여도 사용자 대면 응답은 한국어로 작성하며, 외부 게시 범위가 비어 있으면 실행 전에 한 번의 선택 질문으로 묶어 확인한다.

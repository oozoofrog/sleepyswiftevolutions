# 시리즈 시각 연출과 타이포그래피 결정

> [!info] 요약
> 시리즈 화면은 장식 일러스트나 고정 자막 바 대신 **실제 코드와 그 도메인의 관찰 가능한 결과물**을 전면에 두고, 화자가 지칭하는 순간에만 정확한 문자열을 핀포인트로 강조하며 `CodeGlyphMorph`로 문자 이동을 보여 준다.
> 서체는 `Apple SD Gothic Neo`(산세리프 본문·제목) + `Menlo`(코드·ASCII 코드포인트) + `Atkinson Hyperlegible Next`(핸들·배지) 조합을 기본으로 쓰며, 유니코드 아카이브 편에서는 `AppleMyungjo`와 `Songti`를 더해 `Menlo`의 한글·한자 두부 박스(`□`)를 방지한다.
> 모든 에피소드는 동료 개발자 화법으로 문을 열고, 마지막에는 오프닝 예제의 구체적 값으로 돌아가 제안서가 해결하려던 원래 목표를 짚으며 마무리한다.

## 내용

### 1. 코드 우선 화면과 도메인 시각화 원칙

- **코드 우선(Code-First)과 도메인 결과물 제시**: 비유를 위한 별도 배경 그림 대신, 제목이 약속한 실제 코드와 그 코드가 다루는 도메인의 관찰 가능한 대상을 화면 중심에 놓는다.
  - `SE-0001`: `indexOf(value, ` + `` `in` `` + `: list)`에서 두 백틱이 발화 시점에 제거되는 `CodeReveal`.
  - `SE-0003`: 호출자 슬롯(`x`)에서 매개변수 슬롯(`i`)으로 값이 전달·변경되는 `ParameterValueFlow`(`local` 복사본 vs `inout` 반환).
  - `SE-0005`: 모눈종이 위 시작점 `(10, 20)`에 연필이 먼저 놓인 뒤(`move(to:)`는 선을 긋지 않음), `addLine(to:)`와 `stroke()` 단계에서 종이비행기가 그려지는 `PathDrawing`.
  - `SE-0006`: 결승선 `도착 기록`(`bibs = [3, 1, 2]`) 원본 행과 `번호순 명단`(`order`) 복사본 행을 나란히 두어 `sorted()`와 제자리 정렬 `sort()`를 구분하는 `BibOrder`.
  - `unicode-1.0`: 산수화 배경 그림을 빼고 1992년 초판 인쇄 스캔 지면 자체의 농담·여백·활자 질감을 무대로 삼는다([[유니코드 연대기 파이프라인과 산조 합성]] 참고).
- **낯선 과거 문법의 맥락 선제시**: `Objective-C` 셀렉터(`[path moveToPoint:end]`)나 커링 선언처럼 오늘날 생소한 문법은 퍼즐을 던지기 전에 시대 라벨(`Swift 2`, `Objective-C / UIKit`)과 입력·출력 예시를 먼저 보여 준다.
- **화면 내 자막 바 제거(`SE-0004`~)**: 유튜브에 4개 국어 선택형 자막을 제공하므로 Remotion 본편·쇼츠 화면에서 고정 `SubtitleBar`를 제거해 하단 시각 공간을 확보했다(인스타그램 릴스·로컬 감상용만 `-ko.mp4`로 별도 번인).

### 2. 핀포인트 코드 강조와 연속 모션 (`CodePanel`, `CodeGlyphMorph`, `SharedLayoutTransition`)

제작자 연속 피드백(`2026-11-27`)을 통해 기존의 줄 전체 하이라이트와 빠른 와이프 전환을 폐기하고 아래 규칙으로 확정했다.

1. **발화 전 중립 유지**: 인사말이나 역사적 배경 설명 동안에는 코드를 미리 강조하지 않고 중립 상태로 둔다.
2. **첫 언급 배경 페이드인과 재언급 `108%` 펄스 (`CodePanel.tsx`)**: 화자가 특정 토큰(`targets: [{ line, text }]`)을 처음 부를 때 해당 글자들 뒤에만 앰버 배경이 부드럽게 켜지고, 같은 판본(`long` / `short` 각각 독립 집계) 안에서 동일 철자를 다시 부르면 글자 크기가 잠시 `108%`로 커졌다가 돌아온다.
3. **문자 단위 코드 변형 (`CodeGlyphMorph.tsx`)**: 코드 예제가 다음 형태로 바뀔 때(`moveToPoint(end)` -> `moveTo(end)` -> `move(to: end)`), 두 코드가 공유하는 글자들은 `1.25초` 동안 화면에 남은 채 새 자리로 이동하고 사라지거나 추가되는 기호만 페이드아웃·페이드인한다.
4. **공유 레이아웃 장면 전환 (`SharedLayoutTransition.tsx`)**: 다음 장면에도 이어지는 패널(`[data-layout-id]`)은 장면 전환 시 끊기지 않고 이전 위치·크기에서 `1.25초` 동안 이동하며, 새 보조 패널은 맞닿은 가장자리 뒤에서 나타난다.

### 3. 시리즈 타이포그래피 체계와 `Menlo` 두부 박스 방지

`_context/typography/reading-notes.md`의 Mac 렌더링 시편 비교를 거쳐 창작자가 직접 확정한 서체 조합이다.

| 용도 | Swift Evolution (`src/remotion/theme.ts`) | 유니코드 연대기 (`draw.py` · `thumb.py`) | 선정 이유 및 역할 |
|---|---|---|---|
| 한국어 제목·서사 | `FONT_SANS`: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", sans-serif` | 제목 `AppleMyungjo.ttf`, 본문·주석 `AppleSDGothicNeo.ttc` | 긴 호흡의 한국어 설명 가독성과 아카이브 서적 인쇄 감성(`AppleMyungjo`) 확보 |
| 코드 및 코드포인트 | `FONT_MONO`: `Menlo, "Apple SD Gothic Neo", monospace` | `mono`: `Menlo.ttc` (**ASCII 전용**) | Swift 구문·기호의 고정폭 정렬 유지 (CSS에서는 한글 주석만 `Apple SD Gothic Neo`로 폴백) |
| 인물 핸들·배지 | `FONT_LABEL`: `"Atkinson Hyperlegible Next"` (`src/remotion/fonts/AtkinsonHyperlegibleNext.ttf`) | `label`: `AtkinsonHyperlegibleNext.ttf` | 작은 크기의 영문 계정 핸들·제안서 번호(`SE-0005`, `Swift 3.0`) 자소 식별력 향상 |
| 동아시아 한자·서예 | 해당 없음 | 본문 한자 `Songti.ttc`, 붓글씨 `Kaiti TC` | 한자 대조표(`一`, `青`/`靑`)의 정통 인쇄 자형 재현 |

- **Pillow 렌더러의 `Menlo` 한글·한자 두부(`□`) 함정**: 브라우저 CSS와 달리 Python Pillow(`draw.py`, `thumb.py`)는 자동 글꼴 폴백을 하지 않는다. `Menlo.ttc`에는 한글과 CJK 한자 글리프가 없으므로 `thumb.py` 초기 시안에서 두부 박스와 기준선 어긋남이 발생했고, 이후 `Menlo`는 `U+4E00`·`U+3131` 같은 순수 ASCII 문자열에만 쓰고 한글·한자는 `AppleMyungjo`·`AppleSDGothicNeo`·`Songti`로 엄격히 분리해 해결했다.

### 4. 동료 개발자 화법과 제안서 목표 중심 마무리

- **도입부**: 가로 본편과 세로 쇼츠 모두 코드 화면에서 `"오늘도 코드 한 줄을 함께 살펴보겠습니다."`로 시작해 시청자가 눈으로 풀 수 있는 관찰 질문을 하나 던지고 생각할 휴지를 둔다.
- **클로징(제안서 목표 명시)**: 일반적인 인사말로 끝내지 않고, 오프닝의 구체적 예제 값(예: `SE-0004`의 저장된 `4`와 증가한 `5`, `SE-0006`의 보존된 `[3, 1, 2]`)으로 다시 돌아가 **그 제안서가 원래 해결하려 했던 구체적 문제**를 한 문장으로 분명히 말하며 마친다(반려·철회된 제안서를 다룰 때는 채택된 것처럼 들리지 않게 의도된 목표만 서술).

## 주의할 점

- 창작자가 확정하지 않은 새 장식 효과나 임의의 일러스트 비유를 코드 검증 없이 추가하지 않는다. 비유가 꼭 필요할 때는 대본에서 먼저 시작하고 한국어 실제 용례가 검증된 표현만 쓴다.
- 기여자 카드(`PersonCard.tsx`)를 넣을 때는 상업적 이용이 허용된 사진인지 라이선스를 먼저 확인하고, 허락 근거가 불분명하면 제작자에게 사진을 요청하지 말고 사진을 생략한 채 검증된 영문 이름·계정·역할만 표시한다(`SE-0005`의 Doug Gregor, Dave Abrahams, Radek Pietruszewski 및 `unicode-1.0`의 한국 측 기여자 카드에 동일 적용).

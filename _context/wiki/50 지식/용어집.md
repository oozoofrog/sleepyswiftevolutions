# 용어집

> [!info] 요약
> ‘잠이오는 스위프트 진화의 역사’와 ‘유니코드 연대기’ 제작 파이프라인, 음성 검증 게이트, 시각 컴포넌트, 역사 고증에서 반복해 쓰는 핵심 용어와 정의를 정리한다.

### 유니코드 고증 및 국악 합성 용어

| 용어 | 정의 | 관련 노트 / 경로 |
|---|---|---|
| 원천 분리 원칙 (`Source Separation`) | 대만 `CNS 11643`의 `青`(`U+9752`)과 `靑`(`U+9751`)처럼 단일 기존 국가 표준 안에서 서로 다른 번호로 구분하던 글자는 유니코드에서도 합치지 않고 별도 번호를 유지해 왕복 변환을 보장하는 원칙. | `episodes/unicode-1.0/chronology.ko.md`, [[유니코드 1.0 고증과 18.0 기준 수치]] |
| `CJK-JRG` (후신 `IRG`) | 1990년 2월 서울 회의에서 한국 대표단이 제안해 1991년 7월 도쿄 첫 공식 회의로 출범한 한·중·일 공동연구그룹. 1992년 3월 통합 한자 목록 `URO 2.0`을 확정했다. | `episodes/unicode-1.0/chronology.ko.md` |
| 계면조 퉁소 산조 (`sanjo.py`) | `unicode-1.0`을 위해 `D4`(`293.66 Hz`) 본청 계면조 선율과 `타루`·`농음`·`꺾는음`·`청울림`·장구 장단(`다스름` -> `진양조` -> `중모리` -> `중중모리` -> `자진모리` -> `종지` -> 쿠키 `진양조` 코다)을 물리 모델링으로 합성한 배경 음악. | `episodes/unicode-1.0/sanjo.py`, [[유니코드 연대기 파이프라인과 산조 합성]] |
| `CLDR` | 날짜·숫자·통화 등 언어·지역별 표기 규칙을 정의하는 유니코드 지역화 데이터 저장소. 유니코드 18.0(`175`개 문자 체계)과 짝을 이루는 CLDR 49 기준 `172`개 기본 언어(`185`개 로케일)를 공식 지원한다. | `episodes/unicode-1.0/chronology.ko.md`, [[유니코드 1.0 고증과 18.0 기준 수치]] |

## 주의할 점

- 화면 자막(`caption` / `ko`)에 코드 식별자나 숫자를 적을 때와 TTS 발음용 문자열(`text` / `speech`)을 적을 때의 용도를 혼동하지 않는다. 스키마와 린트는 두 필드의 정합성을 각각 검사한다.
- 새 도메인 컴포넌트나 검증 게이트가 추가되면 이 용어집과 해당 아키텍처 노트를 함께 갱신한다.

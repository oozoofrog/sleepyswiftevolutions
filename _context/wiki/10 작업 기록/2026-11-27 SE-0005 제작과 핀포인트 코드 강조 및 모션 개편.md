# 2026-11-27 SE-0005 제작과 핀포인트 코드 강조 및 모션 개편

## 요청 원문

> 1. 화자 의지 표현 교정: `"살펴봅니다 어색해요 살펴보겠습니다가 맞아요 다른 대사도 비슷한결로 확인 하고 개선하고 교훈 남겨주세요"`
> 2. 도메인 시각화 요청: `"이번에는 그림그리기도 영상에 포함하면 좋겠어요 코드의 도메인과 특징에 맞는 컨텐츠를 보여줍니다"`
> 3. 코드 전환·강조 타이밍 지시: `"코드 전환시에도 모션 그래픽 애니메이션 적용. 화자가 지칭 하기 전에는 코드 강조하지 말것"`
> 4. 후속 검수 피드백(추정): Objective-C 배경 설명 선행, 오프닝 `"남곤"` 발음 부정확 수정, 내보낸 영상 기준 자막 싱크 재정렬, 하단 진행 막대 챕터 제목 줄바꿈, 6장 제목 `"줄이지 않기로 한 이름"`을 `"배열 이름 앞의 NS"`로 구체화, 잔잔한 하우스 비트 배경음 추가(추정).

## 목표와 완료 기준

- 목표: `SE-0005`(`Better Translation of Objective-C APIs Into Swift`)의 `UIBezierPath` 이름 변화를 글자 단위 코드 모핑·발화 시점 핀포인트 강조·종이비행기 경로 드로잉으로 시각화하고 최종 MP4 오디오와 자막 싱크를 검증한다.
- 완료 기준:
  1. 인사말이나 배경 설명 중에는 코드가 중립 상태를 유지하고 화자가 특정 토큰을 발화할 때만 해당 글자가 강조(첫 언급 배경 점등, 재언급 `108%` 펄스)된다.
  2. 코드 변경 시 공유 글자가 `1.25s` 동안 이동(`CodeGlyphMorph.tsx`)하고 장면 간 공통 패널이 이어지며(`SharedLayoutTransition.tsx`) `PathDrawing.tsx`가 위치 이동(`move(to:)`)과 선 그리기(`addLine(to:)`)를 구분해 보여준다.
  3. 내보낸 MP4에서 추출한 실제 오디오와 본편 70개·쇼츠 23개 SRT 구절의 시작 시점이 일치한다.

## 한 일

1. `episodes/SE-0005/research.md`에서 `2015-12-01` 초안(`moveTo(_:)`), `2016-01-25`·`27` Radek Pietruszewski 반론과 Doug Gregor의 `with` 분리 실험(생성 파일 `201`개 PR #5), `2016-02-09`·`10` 전치사 분리 규칙(`050b324593b1`), `2016-03-03` `move(to: end)` 확정 및 Foundation `NS` 접두사 보류를 고증하고 Apple Swift `6.4.2` + iOS Simulator SDK에서 실행 확인했다.
2. 공통 오프닝을 `"오늘도 코드 한 줄을 함께 살펴보겠습니다."`로 고쳐 발표자 다음 행동(`-겠습니다`), 화면 동작(현재형), 역사적 결정(과거형)을 구분했고, `"남본"`처럼 들리던 `"남곤"` 문장을 두 줄 코드 설명으로 재집필했다. 모호했던 6장 제목은 `"배열 이름 앞의 NS"`로 고쳤다.
3. `(10, 20)`에서 시작해 종이비행기를 그리는 `PathDrawing.tsx`, 글자 단위 이동 `CodeGlyphMorph.tsx`, 대소문자 일치 유일 토큰 핀포인트 강조·`108%` 재언급 펄스 `CodePanel.tsx`, 장면 연속 전환 `SharedLayoutTransition.tsx`, 2줄 줄바꿈 `ProgressTimeline.tsx`, `100 BPM` 하우스 배경음(`quiet-pulse.m4a`, `-17.3` / `-17.5 LUFS`)을 구현했다.
4. 내보낸 MP4 오디오를 직접 디코딩해 3월 3일 큐의 약 `570ms` 자막 선행(`166.726s` → `167.296s`)을 잡고 본편 35문장(70구절)·쇼츠 13문장(23구절)을 강제 정렬·파형 대조로 재정렬했으며, 업로드 전 `.mp4.endings.json` 검증을 `uploader.ts`에 연결했다(커밋 `09fea7f`).

## 잘된 점

- `script.json` 메타데이터만 믿지 않고 렌더링된 최종 MP4에서 추출한 오디오 파형으로 자막 싱크를 검증해 `570ms` 누적 오차를 공개 전에 바로잡았다.
- `SceneSchema.superRefine`에서 핀포인트 강조 대상 문자열이 해당 줄에 정확히 한 번만 등장하도록 강제해 엉뚱한 위치가 강조될 가능성을 스키마 수준에서 차단했다.

## 아쉬운 점

- 초기 편집본에서는 Objective-C가 무엇인지 설명하기 전에 Swift 2 `moveToPoint` 퍼즐로 바로 들어가고 줄 전체 하이라이트를 인사말부터 켜 시청자 시선을 분산시켰다.

# 2026-11-28 쇼츠 7편 인스타그램 릴스 공개

## 요청 원문

> 쇼츠들을 릴스로도 올려주세요
> (후속 선택 확정: Chrome `@oozoofrog` 계정 · 공개된 쇼츠 7편 전체 · 한국어 자막 합본 사용 / 2FA 완료 알림: `"로그인완료"`)

## 목표와 완료 기준

- 목표: YouTube에 공개된 세로형 쇼츠 7편(`SE-0001`~`SE-0006` + `unicode-1.0`)을 `@oozoofrog` 인스타그램 릴스에 시리즈 순서대로 한국어 자막 합본·`9:16` 비율·`1080×1920` 맞춤 커버와 함께 공개한다.
- 완료 기준:
  1. 게시 전 `@oozoofrog` 프로필의 기존 릴스 유무를 확인해 중복 게시를 막는다.
  2. 7편 모두 한국어 자막이 하단 여백에 겹침 없이 들어가고 캡션이 `lint-korean.ts`를 통과하며 `9:16` 자르기와 맞춤 커버가 적용된다.
  3. `@oozoofrog/reels/` 탭(`게시물 37`)에서 7개 라이브 URL이 모두 확인되어 `data/instagram-reels-receipt.json`에 기록되고 클립보드·임시 폴더가 정리된다.

## 한 일

1. 작업 전 `ask_question`으로 대상 계정(`@oozoofrog`), 게시 범위(7편 전체), 한국어 자막 번인 방침을 한 번에 확정하고, 인스타그램 2단계 인증 화면에서 즉시 멈춰 사용자 로그인(`"로그인완료"`)을 받은 뒤 프로필(`게시물 30`, 기존 릴스 `0`개)을 확인했다.
2. 인스타그램 웹에서는 별도 SRT 파일을 올릴 수 없으므로 한국어 자막 합본을 준비하되, 무자막본만 있던 `SE-0004`는 `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`로 `subtitles.srt`를 입힌 `episodes/SE-0004/out/SE-0004-9x16-ko.mp4`(`21.78s`)를 생성해 15초 프레임 여백을 검수했다. 7편 캡션 전체에 `scripts/lint-korean.ts`를 통과시키고 `out/reels-staging/`에 영상·커버 14개 파일을 하드링크로 정렬했다.
3. `SE-0001`부터 `unicode-1.0`까지 순서대로 `자르기 선택` 클릭 후 팝오버가 열린 뒤 별도 호출로 `9:16` 세로 자르기를 선택하고, `1080×1920` 맞춤 커버 지정, 클립보드 붙여넣기(`수정 > 붙여넣기`)를 통한 캡션 입력 및 글자 수(`> 0/2200`) 확인, Facebook 동시 공유 끄기를 적용해 7편을 공개했다.
4. `https://www.instagram.com/oozoofrog/reels/`(`게시물 37`)에서 7편 그리드와 각 릴스 모달 주소·캡션을 대조해 `data/instagram-reels-receipt.json`, `.wiki/sources/2026-11-28-instagram-reels-publication.md`, 제작 일지에 기록하고 클립보드와 `out/reels-staging/`을 원상 복구했다.

## 잘된 점

- 2단계 인증 게이트에서 우회 시도 없이 즉시 멈춰 사용자 로그인 후 재개했고, 첫 릴스에서 파악한 웹 작성기 함정들을 표준 절차로 굳혀 나머지 6편을 백그라운드에서 무실패로 연속 게시했다.

## 아쉬운 점

- 인스타그램 웹 작성기가 기본 `1:1` 정사각형 자르기로 열리고 팝오버 오픈과 `9:16` 클릭을 한 번의 `mac-cu` 배치로 묶으면 이전 트리 인덱스를 클릭하며, Lexical 캡션 입력창이 `set_value`를 무시(`0/2200`)해 클립보드 메뉴 붙여넣기로 우회해야 했다.

# 2026-11-26 SE-0003 비유 연출 실험과 코드 중심 기준선 확립

## 요청 원문

> 제작 일지와 9개 연구 스냅샷에서 복원한 단계별 요청 요지(추정):
> 1. `SE-0003` 지역 복사 장면을 위한 시각 연출 시안 3종을 제안하고, 기각 후 가독성 있는 코드 구조를 유지한 40가지 대안 비교 영상과 독립 연출·비유 내레이션 변주를 실험한다(추정).
> 2. 지어낸 한국어 비유 대사가 어색하므로 실제 한국어 사회 담화 용례를 먼저 조사해 바둑 `복기` 파일럿을 시험한다(추정).
> 3. 비유는 정말 도움이 필요한 개념에만 아끼고, 실제 코드와 관찰 가능한 결과를 직접 보여주는 4가지 그래픽 시안과 덜 단조로운 값 변화 모션 4종을 비교한다(추정).

## 목표와 완료 기준

- 목표: 시리즈의 기본 시각 언어가 장식 도해나 일상 비유여야 하는지, 실제 코드와 관찰 가능한 값 변화여야 하는지 비교 실험으로 검증해 기준선을 확정한다.
- 완료 기준:
  1. 코드 없는 장식 시안, 고정 도해 색상 변주, 40개 비유 이야기, 실제 용례 기반 바둑 복기 파일럿, 직접 코드 시안이 렌더링되어 비교 가능해야 한다.
  2. 기각 사유와 최종 채택된 코드 중심 기준선이 편집 지침(`_context/editorial-direction.md`)에 명문화된다.

## 한 일

1. 코드 없이 은유 도형만 그린 초기 3종 시안(`episodes/SE-0003/style-studies/render.py`)과 하나의 도해에 색·모양만 바꾼 40종 비교 릴(`code-atlas.py`)을 제작했으나 모두 기각됐다.
2. 장면 구도와 2문장 비유 내레이션을 각각 달리한 40종 릴(`directed-reel.py`, `metaphors.json`)을 만들고 내부 검수로 화면 동작과 대사가 어긋난 4개 장면을 수정했으나, 창작 비유 대사의 사회적 자연스러움이 부족하다는 평가를 받았다.
3. 국립국어원 자료·지방의회 회의록·바둑 기사 인터뷰의 실제 한국어 표현(`"원본을 복사하다"`, `"복기하다"`)을 조사(`.wiki/sources/2026-11-26-korean-situated-speech.md`)한 뒤 37초 분량 바둑 복기 파일럿(`episodes/SE-0003/studies/baduk/lines.json`)을 제작하고, 왜 `"마음에 걸립니다"`라는 문장이 기보 원본 변경 여부 대신 돌을 살리는 문제로 청자 추론을 유도했는지 분석했다(`.wiki/sources/2026-11-26-metaphor-and-inference.md`).
4. 비유를 걷어내고 실제 코드와 실행 결과를 직접 보여주는 4종 그래픽 비교본(`SE-0003-code-only.mp4`)과 4종 지역 변경 모션 시안(`SE-0003-code-motion.mp4`)을 제작해, 직접 코드 + 관찰 가능한 결과를 시리즈 기본선으로 확정했다.

## 잘된 점

- 왜 바둑 복기 비유가 여전히 인위적으로 들렸는지 청자 기대 추론 관점에서 원인을 규명해, 이후 `SE-0005`(`PathDrawing`)와 `SE-0006`(`BibOrder`)에서 외부 은유 대신 코드 자체의 도메인 산출물을 그리는 원칙으로 직결시켰다.

## 아쉬운 점

- 한국어 실제 담화 용례와 청자 추론 정합성을 먼저 따지기 전에 40개 비유 대본(`metaphors.json`)을 대량 생성해 불필요한 반복 비용이 발생했다.

# 2026-11-28 유니코드 연대기 유튜브 공개

## 요청 원문

> 일단 유니코드를 유튜브에 올려주세요

## 목표와 완료 기준

- 목표: `유니코드 1.0 연대기` 본편(`16:9`)과 쇼츠(`9:16`)를 채널 `잠이오는 스위프트 진화의 역사`(`UCCtGyB0lbnsT0ES0Yuwhwjg`)와 신규 재생목록 `유니코드 연대기`에 중복 없이 공개하고, 맞춤 썸네일 2종과 4개 언어(`ko`, `en`, `ja`, `zh-Hans`) 선택형 자막을 모두 게시한다.
- 완료 기준:
  1. 게시 전 채널 기존 업로드 목록(20개)과 로컬 기록을 대조해 중복 영상이 없음을 확인한다.
  2. 본편·쇼츠 모두 `privacy=public`, `processing=succeeded`, 재생목록 `PLfEnlqRjmO_8` 편입, 맞춤 썸네일 저장, 4개 언어 자막 게시가 YouTube Studio 재열람 및 `upload.ts --verify-only`에서 일치한다.
  3. `episodes/unicode-1.0/out/upload-receipt.json`에 게시 증빙이 저장된다.

## 한 일

1. 채널 `잠이오는 스위프트 진화의 역사`의 기존 업로드 목록(20개)과 로컬 기록을 먼저 대조해 중복이 없음을 확인하고, 본편(`71`큐)·쇼츠(`26`큐) 4개 언어 SRT를 추출했다.
2. `episodes/unicode-1.0/thumb.py`로 `1280×720`·`1080×1920` JPEG 썸네일을 생성·육안 검수하던 중 `Menlo` 폰트가 한글·한자를 두부 박스(`□`)로 그리는 문제를 발견해, ASCII 코드 포인트만 `Menlo`에 남기고 한글 제목·본문과 한자를 각각 `AppleMyungjo`, `AppleSDGothicNeo`, `Songti`로 분리 렌더링했다.
3. `episodes/unicode-1.0/upload.ts`를 실행해 공개 재생목록 `유니코드 연대기`(`PLfEnlqRjmO_8`) 생성, 본편(`eVXZMR9GoK8`)·쇼츠(`UvNizJ4WiqE`) 공개 업로드, 본편 4개 자막 및 쇼츠 `ko` 자막 등록, 재생목록 편입을 마쳤다.
4. `thumbnails.set` 요청 제한(`429 Too Many Requests`)과 쇼츠 다국어 `captions.insert` 할당량 초과(`403 quotaExceeded`) 발생 직후, 재업로드 없이 `upload-receipt.json`의 기존 영상 ID로 Chrome YouTube Studio(`com.google.Chrome` 접근성 제어)에 진입해 본편·쇼츠 맞춤 썸네일 저장과 쇼츠 `en`·`ja`·`zh-Hans` 자막 게시를 완료하고 Studio 재열람 및 `--verify-only`로 검증했다.

## 잘된 점

- 업로드 전에 생성된 썸네일 이미지를 직접 열어 눈으로 확인한 덕분에 영문 고정폭 `Menlo`의 한글·한자 글리프 누락(`□`)이 실제 채널에 올라가는 사고를 사전에 막았다.
- API `429`·`403` 오류 발생 즉시 기존 `videoId` 영수증을 이어받아 Chrome YouTube Studio에서 누락된 썸네일과 자막 3종만 마저 채워 중복 업로드 `0`건을 유지했다.

## 아쉬운 점

- `upload.ts --verify-only` 내부의 `captions.list` 호출도 일일 쿼터를 소모해 쿼터 소진 상태에서는 예외 처리 폴백이 추가로 필요했다. 또한 Chrome 헬퍼 프로세스 이름 중복으로 `mac-cu` 브라우저 확장 모드 대신 `com.google.Chrome` 앱 모드로 전환해야 했다.

## 회고: 지시

- 공개 채널·4개 언어 자막·쿼터 초과 시 Chrome Studio 전환 규칙이 이미 시리즈 표준으로 확립되어 있어 `"일단 유니코드를 유튜브에 올려주세요"` 한 문장으로도 별도 되묻기 없이 완결됐다(추정).

## 회고: 대응

- 게시 전 채널 목록 확인과 원자적 영수증(`upload-receipt.json`) 기록을 결합해 API-브라우저 혼합 게시를 매끄럽게 마쳤다. 검증 스크립트에서도 `captions.list` 쿼터 초과 시 Studio 확인 기록으로 안전하게 폴백하도록 보강했다.
